
# Daily Task Manager

A beginner-friendly task manager built using Python. It helps students and other users organize their everyday responsibilities.

## Features

- Add tasks with a title, description, and due date.
- View all saved tasks.
- Mark tasks as completed.
- Delete tasks.
- Save and load tasks using JSON.
- Validate user input.

## Requirements

- Python 3.8 or newer.
- No external packages required.

## How to Run

1. Open the project folder in PyCharm.
2. Open `main.py`.
3. Click Run or right-click and select Run.
4. Choose an option from the menu.

## Problem Analysis

### Inputs
- Menu choice.
- Task title.
- Task description.
- Optional due date.
- Task number.

### Processing
- Validate user input.
- Store tasks using lists and dictionaries.
- Add, display, complete, and delete tasks.
- Save and retrieve information using JSON.

### Outputs
- Task list and completion status.
- Confirmation messages.
- Error messages for invalid input.
- Saved task records.
